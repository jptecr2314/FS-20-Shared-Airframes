# Merged into FS-20 Vortex Family

Shared airframe stock is now included in [FS-20 Vortex Family](https://github.com/jptecr2314/FS-20-Vortex-Family), starting with version 0.4.0.

Install only VortexConventional.dll. Remove the old Fs20SharedAirframes.dll;
the unified package also includes an optional backup/migration installer.

In F1 / BepInEx Configuration Manager, open **FS-20 Vortex Family > Inventory > Shared airframe stock**.
Enabled shares A/B/C stock and owned cells; disabled keeps separate native counters.
All three aircraft remain available in both modes. No stock is created or redistributed.

This repository is archived for history. Use the unified repository for source,
updates, reports and the current testing status. MIT license and the original
AI-assistance disclosure remain in this historical repository.
